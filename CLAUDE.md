# mody-app-back

## Суть проекта

Бэкенд для получения данных из публичных Google Sheets таблиц, их фильтрации по запросам от клиента и отдачи результатов. Дополнительная фича — создание временных ссылок на отфильтрованный набор данных (TTL 24 часа).

Тестирование через Postman. БД, Redis и авторизация — добавим позже.

## Стек

- NestJS 11 + TypeScript 5.9
- @nestjs/config (env через ConfigModule, isGlobal)
- csv-parse (парсинг CSV из Google Sheets)
- Google Sheets публичный CSV экспорт (без OAuth)
- In-memory кэш (Redis — позже)

## Источники данных (Google Sheets)

| Переменная | Описание |
|---|---|
| `GOOGLE_SHEET_ID` | Прайс-лист (цены для девочек) |
| `GOOGLE_INVENTORY_SHEET_ID` | Инвентаризация (остатки) |

Оба листа — публичные, CSV экспорт без API ключа.
GID в .env не хранится — работает без него.

## SheetsModule

### Эндпоинты

- `GET /sheets` — все продукты с ценами и остатками
- `POST /sheets/refresh` — принудительный сброс кэша

### Структура ответа (Product)

```json
{
  "segment": "1. Составы",
  "brand": "Beneliss",
  "name": "Beneliss ARROZ",
  "volume": 500,
  "prices": {
    "full": 2400,
    "500": null,
    "250": 1300,
    "100": 600,
    "50": 350
  },
  "stock": {
    "bottles": 554,
    "openMl": 450,
    "totalMl": 277450
  }
}
```

### Логика кэша

- Оба листа загружаются параллельно (`Promise.all`)
- Кэш in-memory, TTL 5 минут
- Связка прайс + инвентаризация по `name` (toLowerCase)

### Логика остатков (stock)

- Колонка `Остаток шт` в инвентаризации: `"554,90"` (запятая = десятичный разделитель)
- `bottles` = целая часть = 554 (полных банок)
- `openMl` = дробная часть × volume = 0.90 × 500 = 450мл (открытая банка)
- `totalMl` = отдельная колонка `Остаток мл`
- Если продукт не найден в инвентаризации → `stock: null`

### Заголовки прайс-листа

Таблица имеет 2 строки заголовков. Строки объединяются:
- row1: `"Ціни дівчат"`, `""`, `""` ...
- row2: `"РРЦ"`, `"500"`, `"250"` ...
- Результат: `"Ціни дівчат РРЦ"`, `"Ціни дівчат 500"`, `"Ціни дівчат 250"` ...

## FilterModule

### Эндпоинт

`GET /filter?segment=...&brand=...&name=...`

Все параметры опциональны. Несколько параметров одновременно = AND-логика.
Поиск по подстроке, регистр игнорируется.

### Примеры

```
GET /filter?brand=Beneliss
GET /filter?segment=Составы&brand=Beneliss
GET /filter?name=SOS
```

## Планируемые модули

### ShareModule (делаем после логина)

Флоу:
- Админ фильтрует продукты → нажимает "Создать ссылку"
- `POST /share` принимает `{ products: [...] }` → сохраняет снимок in-memory с TTL → возвращает `{ token, expiresAt }`
- `GET /share/:token` → отдаёт сохранённые продукты (или 404 если истекло)
- Публичная страница `myapp.com/share/:token` — только просмотр, без логина
- POST защищён JWT (только админ может создавать ссылки)
- TTL: 5 минут для теста, потом 24 часа
